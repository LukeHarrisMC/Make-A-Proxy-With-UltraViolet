# Make-A-Proxy-With-UltraViolet
Instructions on how to make infinite proxy's
Step 1.
Run this command to set up the Base and start up UltraViolet.

```bash startproxyserver.sh```

Step 2. Find port 8080. Now set it to public.

Step 3. Go to the ports tab and click the Globe🌐 Icon to launch the proxy.

Step 4. Now search the site you want. E.G. Discord.Com. and hit enter.
